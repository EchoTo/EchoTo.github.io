每次开组会，我都是对着 GitLab 上的提交记录，一个仓库一个仓库地回忆这周干了什么。很麻烦。

10 月 10 日下午，我让 Claude Code 帮我做一张贴在桌面上的卡片，专门干这件事。15:47 提交第一个版本，只能写周报；到 17:18，它已经能写站会、看仓库状态、看 Claude Code 用量、列待办、看发布、估工时、起草 OKR。前后一个半小时。

后来它就一直贴在我的桌面上，叫 DevCards。最近把它开源了。

![DevCards 自动切换各个标签（示例数据）](/img/devcards-demo.gif)

## 它做什么

一张卡片，几个标签，数据都来自本机的 git 仓库和 Claude Code：

- **周报、站会、OKR**：把提交记录交给 Claude，整理成能直接念的文字；
- **仓库**：哪些仓库有没提交的改动、没推送的提交；
- **用量**：今天和这周的 Claude Code token 用量，按项目、按模型拆开；
- **待办、发布、工时**：接公司的工单系统和 GitLab，看分给我的工单、等我审的合并请求、各环境跑的版本。

前五个只要本机有 git 和 claude 就能用；后面几个要在配置里填数据源。

## 几个我觉得做对了的地方

**每个小组件只负责写一个 Markdown 文件。** 卡片本身只做一件事：把这些文件渲染出来。想加一个标签，就是写一个 Python 脚本，往数据目录里写一个 `.md`。卡片不需要知道数据从哪来。

**它贴在桌面上，不抢窗口。** 卡片在桌面图标之上、所有普通窗口之下，平时被挡住，回到桌面一眼就能看到，不会像通知一样打断我。

**写到外部系统之前，一定要我确认。** 工时是按提交里出现的工单号估算的，估出来只显示在卡片上；只有我点了登记、确认之后，才会真的写进工单系统。AI 可以替我整理，但替我提交，我还是想自己按一下。

## 用起来

需要 macOS 13 以上，以及登录好的 `claude` 命令行：

```bash
git clone https://github.com/TonkyShan/devcards.git
cd devcards
./install.sh ~/code    # 存放各个仓库的目录
```

想先看看效果，`./demo.sh` 会用示例数据单独打开一张卡片，不碰你自己的数据。

界面目前是中文的。代码在 [GitHub](https://github.com/TonkyShan/devcards)，MIT 协议，欢迎提 issue。
